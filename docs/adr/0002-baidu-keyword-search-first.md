# ADR-0002: 百度网盘源首版仅提供文件名关键词检索，双击执行结果目录定位

- 状态：已接受（2026-10-22）
- 影响范围：search/baidu_search.py、ui/main_window.py

## 背景

百度网盘开放平台提供两类文件检索：关键词检索（`xpan/file?method=search`，
文件名匹配，全盘）与语义检索（`xpan/unisearch`，自然语言 + 文档内容/OCR/ASR，
依赖账号等级）。实测授权账号（非 VIP）语义检索返回空数据，无法验证效果。

## 决策

1. 首版**只实现关键词检索**；语义检索作为后续增量（接口已调研清楚，
   加上是纯增量，不影响现有结构）。
2. 双击结果 = **结果目录定位**：打开网页版网盘并定位到文件所在目录。
   不创建分享链接（需额外审核权限且有泄露风险），不做 docpreview 直链（8 小时
   有效、仅文档类可用，留作右键增量）。

## 展示截断

关键词检索单次响应可能上千条（实测一个常见词约 1000 条）。以
`search_baidu(query, limit=...)` 在映射层截断（默认 100），
与 Everything 侧 count 上限的产品约定保持一致。

## 后果

- 非 VIP 用户开箱可用；VIP 用户也不会因缺少语义检索而受阻（后续增量）。
- 用户预期管理：文档与故障排查需明示"当前为文件名检索"。
